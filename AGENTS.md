# Agent instructions

Read [CONTRIBUTING.md](CONTRIBUTING.md) first: its commands and rules apply to you. In addition:

- Open an issue or pull request only when a person asks for that one.
- Before the person asks for review, have the change reviewed by a fresh session that hasn't seen the work, ideally on a different model, and address what it finds.
- In the pull request description, name the tool you are and what you did, as CONTRIBUTING.md requires.
